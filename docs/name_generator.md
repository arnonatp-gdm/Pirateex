# Name Generator Documentation

## Captain and Ship Name Generation
- Names for captains and ships should be unique and thematic, reflecting the pirate ethos.
- Names are randomly generated using specified adjectives, nouns, and modifiers.

## Name Generation Logic
1. Define a list of adjectives and nouns related to pirates.
2. Randomly select one of each to create names.
3. Ensure generated names are not repeated and align with thematic elements defined in the project specifications.

## Usage
Call the function `generate_name()` to receive a randomly generated pirate name.
